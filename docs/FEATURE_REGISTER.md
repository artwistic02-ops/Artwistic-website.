## QA status (full build)

**Static review performed on every commit:** every `{% schema %}` JSON block and every JSON template touched was parsed and validated; Liquid `if`/`for`/`case`/`unless`/`capture` tag nesting was balance-checked in every new/edited file; every asset (`.css`/`.js`) referenced from a `stylesheet_tag`/`<script src>` was cross-checked against the actual file on disk (none missing); every metafield/metaobject reference was cross-checked against [METAFIELDS.md](METAFIELDS.md)/[METAOBJECTS.md](METAOBJECTS.md); every icon SVG referenced (`inline_asset_content`) was confirmed to exist in `assets/`.

**Architectural review performed:** before each feature, checked whether Dawn already solved the problem (collection filters, predictive search, cart drawer, mega menu, product accordion — all extended or restyled instead of rebuilt) versus needing genuinely new code (wishlist, recently viewed, stack builder, Shop the Look, breadcrumbs — Dawn had no equivalent).

**Not performed (environment limitation):** this build environment has no Shopify CLI, no Node/npm, and no connected Shopify store, so the following could not be executed and remain to be done before launch:
- Live Theme Editor check — add/remove/reorder every new block type; confirm every section's schema renders without error in the actual editor (not just JSON-valid).
- Shopify Theme Check (`shopify theme check`) — install the Shopify CLI and run it against this theme; fix any Liquid-specific lint issues a static JSON/regex check can't catch (unused variables, deprecated filters, missing `theme-check-disable` scoping, etc.).
- Manual functional QA: mega menu hover/click/keyboard on desktop and touch on mobile; wishlist persistence across reloads; Build Your Stack add-to-cart with a real cart; Shop the Look hotspot popovers at real image sizes; sticky Add to Cart bar behavior on real iOS/Android Safari/Chrome.
- Manual cross-browser/responsive QA (spec sections 72–78): keyboard nav, screen reader pass, 320/375/390/768/1024/1440px layouts, Safari safe-area/dynamic-viewport behavior.
- Lighthouse performance/SEO audit against a real (non-placeholder) catalogue and images.
- Validating the `BreadcrumbList`/`Product`/`Article` JSON-LD output with Google's Rich Results Test against live pages.

**Recommended next step:** connect this theme to a Shopify store (upload the zip, or `shopify theme dev` from a machine with Node), then work through [SHOPIFY_ADMIN_SETUP.md](SHOPIFY_ADMIN_SETUP.md) end-to-end (every metafield, metaobject, menu, and page it lists) before running the QA checklist above.

## How to use this register

Before building a backlog item: re-read its "Design intent" row, check whether the underlying Shopify capability (metafield/metaobject/menu) already exists from an earlier feature, and add a new row to the "Shipped" table plus a changelog entry once it lands.
